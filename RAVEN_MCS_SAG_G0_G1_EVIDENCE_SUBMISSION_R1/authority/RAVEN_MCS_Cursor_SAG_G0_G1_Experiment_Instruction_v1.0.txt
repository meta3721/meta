四、核心时间顺序：必须逐行实现
============================================================

每个 window r 必须严格执行：

1. completed-history update
2. compute predictable SAG certificates from F_{r-}
3. compute and freeze G_r
4. realize current R
5. compute/freeze p_hat_obs from legal pre-O history
6. realize current O
7. form registered set E_r
8. compute corrected mass m_{k,r}
9. form pre-U positive-mass training set B_r
10. construct normalized record weights/compositions/n_eff on B_r
11. local training / local attempt
12. compute/freeze q_hat_use from legal pre-U history
13. realize current U
14. form A_r = B_r cap U_r
15. usable-update correction
16. construct beta_hat, M_r, V_r, C_r
17. solve P2
18. global update
19. optional Debt update
20. post-window Full/No-Design counterfactual audit
21. append audit quantities to future Gate state only

必须新增：

  B_r = {k in E_r : m_{k,r} > 0}

以及：

  A_r = {k in B_r : U_{k,r}=1}

不要再用 A_r 做 pre-U local training set。

============================================================
五、Full Design / No-Design / SAG 三种模式
============================================================

实现三个模式：

Mode D：Always-Design
  G_r = 1
  zeta_tilde = zeta_hat^D

Mode 0：No-Design RAVEN
  G_r = 0
  zeta_tilde = 1

Mode SAG：
  G_r 由 SAG certificate 决定
  zeta_tilde = 1 + G_r * (zeta_hat^D - 1)

三种模式必须使用相同：
  train/val split
  random seed
  EventTrace
  R/O/U realization
  deadline trace
  staleness trace
  initialization
  local steps
  learning rate
  P2 parameters
  target map
  observation/usable propensity models

============================================================
六、SAG Gate 输入
============================================================

在线 Gate 使用：

  C_cov_LCB
  C_ret_LCB
  C_ESS_LCB
  C_clip_UCB
  delta_A_UCB
  B_tot_UCB

其中：

  B_tot_UCB
  =
  B_srv_UCB
  +
  2 * delta_A_UCB
  +
  2 * delta_cal

Gate：

  G_r = 1 iff

    C_cov_LCB  >= tau_cov
    C_ret_LCB  >= tau_ret
    C_ESS_LCB  >= tau_ESS
    C_clip_UCB <= tau_clip
    delta_A_UCB <= tau_A
    B_tot_UCB <= tau_safe

否则：

  G_r = 0

任何以下情况也必须 fail closed：

  certificate missing
  NaN / inf
  insufficient history
  model outside calibrated range
  cold start
  confidence bound unavailable

============================================================
七、certificate 模块：先简单、可审计
============================================================

本轮不使用神经网络 Gate。

允许优先实现：

A. delta_A_UCB
  低维 logistic / isotonic / empirical-bin calibration
  + one-sided upper calibration

B. Delta_beta / Delta_M / Delta_V upper bounds
  rolling quantile / calibrated quantile
  或简单低维 quantile regression

C. C_cov
  使用 opportunity probability 的 one-sided lower bound
  不得直接把 smoothed positive estimate 当 positivity certificate

D. C_ret / C_ESS / C_clip
  使用 completed-window history 生成 predictable lower/upper bound

优先原则：
  简单
  稳定
  可解释
  可复算
  可输出 coverage
