RAVEN-MCS V2.3：给 Cursor 的完整实验实现指令
============================================================

用途
----
将本文件整体交给 Cursor。Cursor 必须把自己视为本项目的“首席研究工程师 + 实验审计员”，
不是只写一个能运行的 demo，而是构建一套能够支撑高水平论文的、可复现、可审计、
数学定义与实现完全一致的实验仓库。

论文题目
--------
RAVEN-MCS: Target-Risk-Calibrated Asynchronous Federated Data Completion
under Two-Stage Non-Random Selection

中文题目
--------
RAVEN-MCS：两阶段非随机选择下目标风险校准的异步联邦数据补全

一、你的角色、总目标与工作方式
==============================

1. 你的角色
------------
你是本项目的首席研究工程师。你必须同时承担以下职责：

1) 将论文 V2.3 的系统模型、算法、理论量和实验指标实现为代码；
2) 建立可复现的数据处理、事件模拟、训练、统计分析和制图流水线；
3) 使用自动化测试验证数学定义，而不是只检查程序是否崩溃；
4) 保证不同方法使用相同数据划分、相同事件轨迹、相同模型骨干和相同预算；
5) 对每一次运行保存配置、环境、Git 状态、数据哈希和结果哈希；
6) 遇到数据、公式或实现边界不清楚时，停止相关主实验并在 ISSUES.md 中明确报告；
7) 严禁为了得到“好看结果”而改变事件、指标、目标分布或测试口径。

2. 总目标
---------
建立一套窗口化异步联邦数据补全平台，完成以下证据链：

A. 证明原始到达分布可能明显偏离部署目标分布；
B. 分解机会不平衡、观测选择和可用更新选择造成的目标风险错位；
C. 验证 RAVEN-MCS 的两阶段校正、当前组校准和长期目标债务能够降低该错位；
D. 验证理论中的 pair discrepancy、group discrepancy、target debt、window reachability、
   variance proxy 和 calibration residual 在实验中具有对应可观测量；
E. 验证方法在 Balanced 场景不产生明显伤害；
F. 验证弱支持、模型错设和隐藏混杂下仍存在可解释的残余误差；
G. 测量额外计算、通信、内存和收敛时间开销。

二、不可违反的“实验宪法”
========================

以下规则高于任何性能目标。违反任意一条的结果不得进入论文。

1. 公共预测对象
---------------
所有方法预测同一个公共城市级值 Y_i：

    i = (n, t)
    Y_hat_i = f_theta(i; C_i^dep)

禁止：
- 让预测目标依赖客户端 ID；
- 将每个客户端自己的测量值当成独立预测任务；
- 在 Common-NDMF 中加入 client_id embedding；
- 不同方法使用不同测试上下文或测试掩码。

2. 原子单元与机会分层
---------------------
原子单元：

    i = (n, t)

其中 t 是绝对时间槽。绝对时间槽一般只出现一次，因此不得用逐原子单元历史计数估计机会概率。

必须定义可重复机会分层：

    s(i) = (coarse_spatial_region, time_of_day_block, weekday_or_weekend)

目标组：

    h(i) = (evaluation_spatial_unit, target_time_block)

h 用于目标风险、组校准和债务；
s 用于估计重复机会分布。
s 可以比 h 更粗，但必须通过验证集冻结。

3. 窗口化异步时序
-----------------
服务器聚合窗口：

    W_r = [T_r, T_{r+1})

窗口内：
- 服务器保持 theta_r 固定；
- 客户端可以从旧版本 theta_{s_{k,r}} 开始训练；
- 更新可以在窗口内不同时间到达；
- 单个到达不得立即更新全局模型。

窗口关闭时：
- 形成一次 usable set A_r；
- 联合求解一次 P2；
- 只产生一次 theta_{r+1}；
- 更新一次 target debt。

禁止“每到达一个更新就递增模型版本”。

4. 两阶段选择边界
-----------------
第一阶段：观测选择。

风险集 R_{k,r} 必须在观测结果之前确定。
对 i in R_{k,r}：

    O_{k,r,i} in {0,1}
    p_obs_{k,r,i} = P(O=1 | X_obs, history_before_outcome)

X_obs 只能包含事前信息，例如：
- 距离；
- 时段；
- 感知日程；
- 设备状态；
- 历史访问；
- 区域热度；
- 可达性。

禁止使用：
- Y_i；
- 当前测量误差；
- 当前模型误差；
- 当前观测结果；
- 未来信息。

第二阶段：可用更新选择。

所有具有非空观测缓冲的客户端必须先注册尝试：

    E_r = {k : observed_buffer_nonempty}

可用结果：

    U_{k,r} = 1{
        local computation succeeds,
        network transmission succeeds,
        arrival is before T_{r+1},
        tau_{k,r} <= S_max
    }

失败、超时、网络中断和过期客户端必须保留 U=0 标签。
禁止只记录成功上传的客户端。

q 模型只能使用注册时可得信息。禁止使用：
- realized computation time；
- realized network delay；
- realized arrival time；
- post-outcome arrival staleness；
- 当前 update vector；
- 当前 update norm；
- 当前 loss improvement。

5. 方法无关的事件轨迹
---------------------
同一 seed 下，所有方法必须读取完全相同、只读的 EventTrace。

EventTrace 必须包含：
- risk set；
- opportunity unit；
- opportunity features；
- O；
- registration time；
- downloaded version；
- computation success；
- computation duration；
- network success；
- network duration；
- arrival time；
- U；
- pre-outcome device/network states。

事件生成不得依赖具体方法的权重或最终 alpha。
特别注意：
- 计算时延生成器必须使用方法无关的 raw workload、raw observed count、
  fixed local steps、device profile 等；
- 不得用 RAVEN 特有的 corrected mass m 改变真实 U；
- m 可以作为 q 估计模型的预测特征，但不能反向改变已经冻结的事件结果。

6. P2 信息边界
--------------
P2 可以使用：
- Q_r；
- M_r；
- beta_hat_r；
- lagged variance V_r；
- staleness；
- correction summaries；
- feasible constraints。

P2 禁止读取当前随机更新向量 u_{k,r} 的坐标、范数或方向来决定该更新自身权重。
必须先求 alpha，再聚合 u。

7. 测试与调参边界
-----------------
- 时间顺序划分 train/validation/test；
- 所有归一化统计仅用 train；
- 验证集用于模型和超参数选择；
- 测试集仅在配置冻结后运行；
- 不得根据测试结果再次调参数；
- 所有方法使用相同测试目标权重；
- 不得挑选对本方法有利的时间区间。

8. 不夸大能力
-------------
RAVEN-MCS 只处理可观测、条件可忽略的选择。
不得声称解决：
- 任意 MNAR；
- 任意隐藏混杂；
- 无支持目标区域；
- 密码学隐私；
- 新的差分隐私保证。

三、必须严格实现的数学定义
==========================

1. 目标质量
-----------
目标原子质量：

    varpi_i^tar = mu_{h(i)} * nu_{i|h(i)}^tar

目标客户端—机会分层质量：

    pi_{k,s}^tar = Lambda_s^tar * lambda_{k|s}^tar

目标客户端—原子单元质量：

    pi_{k,i}^tar = pi_{k,s(i)}^tar * nu_{i|s(i)}^tar

所有目标质量必须非负并归一化。

2. 机会设计比
-------------
一般形式：

    zeta^o_{k,r,i}
      = [pi^tar_{k,s(i)} / pi^opp_{k,s(i),r}]
        * [nu^tar_{i|s(i)} / nu^opp_{k,r}(i|s(i))]

默认主实验使用分层内交换性：

    nu^opp_{k,r}(i|s) = nu^tar_{i|s}

因此：

    zeta_hat_{k,r,s}
      = pi^tar_{k,s} /
        max(pi_hat^opp_{k,s,r}, pi_min)

机会概率使用滞后记录估计，不得使用当前窗口结果。
默认采用指数遗忘：

    C^opp_{k,s,r}
      = rho_opp * C^opp_{k,s,r-1}
        + N^opp_{k,s,r-1}

    pi_hat^opp_{k,s,r}
      = (C^opp_{k,s,r} + smoothing)
        / sum_{j,u}(C^opp_{j,u,r} + smoothing)

3. 第一阶段校正
---------------
组合权重：

    a_{k,r,i}
      = min{
          a_max,
          zeta_hat_{k,r,i}
          / max(p_hat_obs_{k,r,i}, p_min)
        }

组质量：

    m_{k,r,g}
      = sum_i O_{k,r,i} a_{k,r,i} 1{h(i)=g}

总质量：

    m_{k,r} = sum_g m_{k,r,g}

Hájek 归一化记录权重：

    a_bar_{k,r,i}
      = O_{k,r,i} a_{k,r,i} / m_{k,r}

组组成：

    c_{k,r,g} = m_{k,r,g} / m_{k,r}

有效样本量：

    n_eff_{k,r}
      = m_{k,r}^2 /
        sum_i (O_{k,r,i} a_{k,r,i})^2
      = 1 / sum_i a_bar_{k,r,i}^2

注意：
- m 是目标等价质量；
- n_eff 是权重集中度；
- 二者严禁混用。

4. 本地目标和归一化更新
-----------------------
本地目标：

    F_hat^H_{k,r}(theta)
      = sum_i a_bar_{k,r,i}
        * 0.5 * (f_theta(i, context) - Z_{k,r,i})^2

本地训练从 theta_{s_{k,r}} 开始，执行 E_loc 步 SGD。

归一化位移：

    u_{k,r}
      = (theta_{s_{k,r}}
         - theta_{k,r}^{(E_loc)})
        / (gamma_r * E_loc)

所有同骨干方法必须使用同样的模型、初始化、local steps 和优化预算。

5. 滞后方差
-----------
当前 P2 使用的方差必须来自当前随机更新之前的滞后状态：

    v_{k,r}
      = S_bar^2_{k,r^-}
        / max(n_eff_{k,r}, 1)
        + v_floor

当前窗口计算出的梯度方差只能更新未来窗口状态。

6. 第二阶段校正
---------------
稳定 inverse usable propensity：

    d_{k,r}
      = min{
          d_max,
          1 / max(q_hat_use_{k,r}, q_min)
        }

两阶段质量：

    b_{k,r} = m_{k,r} * d_{k,r}

参考权重：

    beta_hat_{k,r}
      = b_{k,r}
        / sum_{j in A_r} b_{j,r}

必须检查：

    beta_hat >= 0
    sum beta_hat = 1

7. 目标债务
-----------
覆盖矩阵：

    M_r = [c_{k,r}]_{k in A_r}

当前有效组混合：

    omega_r = M_r alpha_r

债务：

    Q_{r+1}
      = [Q_r + eta_r (mu - omega_r)]_+

空窗口：
- theta 不更新；
- Q 不更新；
- S_R 不增加。

8. P2
-----
每个 active window 求解：

    minimize over alpha in C_r:

      - Q_r^T M_r alpha

      + (lambda_g / 2)
        ||M_r alpha - mu||_2^2

      + (lambda_beta / 2)
        ||alpha - beta_hat_r||_2^2

      + (lambda_v / 2)
        alpha^T V_r alpha

      + lambda_s
        tau_bar_r^T alpha

约束：

    1^T alpha = 1
    0 <= alpha_k <= alpha_bar_r
    ||alpha||_2^2 <= 1 / E_bar_r

其中：

    alpha_bar_r
      = min(1, max(alpha_max, 1/K_r))

    E_bar_r
      = min(E_min, K_r)

必须配置验证：

    lambda_beta > 0
    lambda_g >= max_server_learning_rate

P2 必须是凸问题。
主结果优先使用 CVXPY + CLARABEL。
需要记录：
- solver status；
- objective value；
- primal residual；
- solve time；
- constraint violations；
- fallback usage。

9. 全局更新
-----------
P2 求出 alpha 后：

    theta_{r+1}
      = theta_r
        - eta_r
          sum_{k in A_r}
          alpha_{k,r} u_{k,r}

10. 理论诊断量
--------------
有效 pair 分布：

    Pi_hat_{k,i}^{(m)}
      = [sum_r eta_r I_r alpha_{k,r}^{(m)}
                  w_{k,r,i}^{(m)}]
        / S_R

RAVEN 中：

    w_{k,r,i} = a_bar_{k,r,i}

记录未参与当前本地目标时：

    w_{k,r,i} = 0

组分布：

    omega_hat_g
      = sum_k sum_{i:h(i)=g} Pi_hat_{k,i}

group mismatch：

    Delta_group = ||omega_hat - mu||_1

controlled pair mismatch：

    Delta_pair = ||Pi_hat - pi^tar||_1

real trace client-stratum mismatch：

    Delta_c-s
      = sum_{k,s}
        |Pi_hat_{k,s} - pi^tar_{k,s}|

平均当前组差异：

    avg_delta_group
      = sum_r eta_r I_r
        ||M_r alpha_r - mu||_1
        / S_R

平均参考偏离：

    avg_delta_ref
      = sum_r eta_r I_r sqrt(K_r)
        ||alpha_r - beta_hat_r||_2
        / S_R

归一化债务：

    debt_normalized
      = ||Q_R||_1 / S_R

确定性债务上界检查：

    ||omega_bar_R - mu||_1
      <= 2 ||Q_R||_1 / S_R

必须对每一个前缀 r 都检查该不等式，容差 1e-8。

11. 目标和到达风险
------------------
测试目标 RMSE：

    RMSE_mu
      = sqrt[
          sum_{i in test}
          varpi_tilde_i^tar
          (Y_hat_i - Y_i)^2
        ]

到达 RMSE 必须使用原子单元级到达权重：

    RMSE_rho
      = sqrt[
          sum_{i in test}
          rho_tilde_i^arr
          (Y_hat_i - Y_i)^2
        ]

禁止仅用组级到达分布代替原子单元分布。

测试期原子单元到达强度由冻结的机会与选择模型预测：

    r_hat_i^arr
      = sum_k
        pi_hat^opp_{k,s(i)}
        * nu_hat^opp_k(i|s(i))
        * p_hat_obs_{k,i}
        * q_hat_use_{k,s(i)}

再在 test support 上归一化。

错位间隙：

    Gap_mis = RMSE_mu - RMSE_rho

五、工程质量标准
================

1. Python
---------
- Python 3.11；
- 完整类型标注；
- dataclass 或 Pydantic 配置对象；
- pathlib 处理路径；
- 不在核心逻辑中写全局可变状态；
- 函数职责单一；
- 对关键张量形状写断言；
- 关键数学函数写 docstring，注明对应论文公式；
- 所有随机数均从显式 seed/RNG 对象获得。

2. 确定性
---------
实现：

    seed_everything(seed)

至少设置：
- random；
- numpy；
- torch CPU；
- torch CUDA；
- deterministic algorithms；
- cuDNN deterministic；
- PYTHONHASHSEED。

每个 run 保存：
- master seed；
- data seed；
- event seed；
- model seed；
- solver seed；
- bootstrap seed。

3. 配置
-------
使用 Hydra/OmegaConf 或严格 YAML。
任何可影响结果的参数都必须进入配置并写入 manifest。
禁止隐藏 hard-coded 参数。

4. 日志
-------
控制台日志应简洁。
详细窗口日志写 Parquet/JSONL。
不得把每个模型参数和每个 update vector 全量写入日志。
保存必要的摘要和可选 debug dump。

5. 错误处理
-----------
- 数据字段缺失：明确报错；
- solver infeasible：保存输入快照并停止该 run；
- 空窗口：按定义处理；
- NaN/Inf：立即失败并保存最近 checkpoint；
- propensity 全为常数或退化：发出 hard warning；
- test leakage：测试直接失败；
- resume 时配置哈希不同：拒绝继续。

Phase 5：Common-NDMF
--------------------
实现所有主方法共享的公共预测模型。

默认结构：
- spatial embedding: 32；
- time encoding: hour/day sin-cos + weekday + normalized trend；
- time MLP -> 32；
- interaction:
  [e_n, e_t, e_n * e_t, abs(e_n - e_t)]；
- head:
  128 -> 64 -> 32 -> 1；
- ReLU；
- dropout 0.1。

禁止 client embedding。

输出：
- 标准化域标量；
- 评价前反标准化。

主理论实验：
- local SGD；
- Adam 仅放工程鲁棒性。

需要测试：
- forward shape；
- no client id；
- deterministic initialization；
- same initial checkpoint across methods；
- inference uses public deployment context。

Phase 6：联邦窗口训练器
-----------------------
实现 WindowRunner。

每个 r：
1) 加载 theta_r；
2) 从 EventTrace 读取所有风险集和 O；
3) 计算 correction summaries；
4) 注册 E_r；
5) 各方法在相同 downloaded checkpoint 上本地训练；
6) 使用 EventTrace 的 U 形成 A_r；
7) 空窗口按定义处理；
8) active window 求 aggregation weights；
9) 一次更新 theta_{r+1}；
10) 更新 debt；
11) 保存 checkpoint 和 window metrics；
12) 当前窗口记录只允许更新下一窗口估计器。

严格断言：
- 窗口内 theta hash 不变；
- 每个 active window 只更新一次；
- E_r 在 local completion outcome 前确定；
- A_r subset of E_r；
- alpha 与 update coordinates 无依赖。

Phase 8：所有方法
-----------------
实现统一 Aggregator 接口：

    fit_or_prepare(...)
    compute_local_weights(...)
    compute_server_weights(...)
    update_state(...)

方法精确定义：

1) Central-All
- 使用所有有效观测；
- 不受 compute/network loss；
- 信息丰富参考；
- 不称理论上界。

2) Central-Delivered
- 只使用最终 usable attempts 对应的原始观测；
- 与联邦方法共享实际可达信息。

3) FedAvg-Window
- alpha proportional raw sample count；
- 无 staleness correction；
- 无 selection correction。

4) FedAsync-Window
- alpha proportional raw count * exp(-kappa_tau * tau)；
- 窗口内联合归一化。

5) TimeAlign-Agg
- 同 Common-NDMF；
- 仅时间/陈旧度对齐；
- 无 target correction。

6) FLAMF-Original
- 外部系统基线；
- 单独 adapter；
- 不用于组件级公平结论；
- 若复现不完整，记录差异，不伪称原始实现。

7) Local-Hajek
- zeta + p correction；
- 本地 Hájek；
- server 不校正 q；
- 无 target debt/P2。

8) TwoStage-Hajek
- zeta + p + q；
- alpha = beta_hat；
- 无 debt、variance、staleness optimization。

9) Inst-Cal
- 完整 correction；
- P2 有 group/reference/variance/staleness；
- Q 固定 0，不使用 debt pressure。

10) Debt-Cal
- 无 zeta/p/q correction；
- 使用 raw local composition；
- 有 instantaneous group calibration 和 debt。

11) RAVEN-MCS
- 完整方法。

12) RAVEN-SimOracle
- controlled only；
- generating design/obs propensity；
- Monte Carlo q；
- 其余流程同 RAVEN。

消融：
- w/o Design；
- w/o Obs；
- w/o Use；
- w/o Inst；
- w/o Debt；
- w/o Ref；
- w/o Var；
- w/o Stale；
- No Forget；
- Current-Var。

Current-Var 仅作为反例/诊断，不进入主要正确性结论。

Phase 9：P2 与 debt

A. p2_cvxpy.py

B. p2_projected.py
- 规模实验；

投影需同时处理：

P2 测试：
- alpha sum = 1；
- nonnegative；
- alpha <= alpha_bar；
- norm2 squared <= 1/E_bar；
- repeated solve stable；
- lambda_beta > 0 时唯一；
- K_r=1；
- empty window；
- beta on boundary；
- high debt；
- infeasible config validation。

十七、常见错误与调试顺序
========================

1. 所有方法无差异
-----------------
依次检查：
- raw arrival 是否真的偏离 target；
- Delta_pair 是否非零；
- client bias sigma_b 是否非零；
- target groups 是否过粗；
- opportunity/p/q 是否近常数；
- target risk 与 arrival risk 是否错误地使用相同权重；
- 模型是否偷偷用了 client id；
- correction 是否被 clipping 全部压平。

不要首先调大 lambda。

2. RAVEN 在 Balanced 明显变差
-----------------------------
检查：
- zeta 是否应接近 1；
- p/q calibration；
- clipping；
- ESS；
- alpha_max/E_min；
- lambda 过大；
- reference 是否错误；
- local loss 是否重复归一化；
- m 和 n_eff 是否混用。

3. SimOracle 反而错位更大
------------------------
检查：
- zeta 分子分母方向；
- q 是 P(U=1) 还是 inverse；
- beta 是否乘 m；
- U=0 attempts 是否保留；
- Monte Carlo 固定 pre-state；
- normalization support；
- EventTrace 是否一致。

4. debt bound 失败
------------------
检查：
- S_R 是否只累计 active windows；
- empty window 是否更新 Q；
- omega 是否概率向量；
- alpha sum；
- Q projection；
- eta weighting；
- prefix indexing；
- floating precision。

5. P2 infeasible
----------------
检查：
- alpha_bar >= 1/K；
- E_bar <= K；
- uniform vector feasibility；
- wrong L2 constraint；
- NaN beta/V/tau；
- config validation。

6. q 看起来非常准确但无校正效果
------------------------------
检查：
- q 是否只在成功样本上训练；
- q features 是否泄漏 outcome；
- q 是否实际非均匀；
- second-stage correction 是否被 d_max 全部截断；
- m 是否错误为 raw count；
- complete-counteracting 场景是否使单阶段效应抵消。

7. 运行过慢
-----------
先 profile：
- data loader；
- local model；
- P2；
- Monte Carlo oracle；
- logging。

优化顺序：
- cache EventTrace；
- cache oracle q；
- vectorize local weights；
- batched client training；
- reduce debug logs；
- parallelize seeds；
- 最后才考虑近似 P2。

不得为提速改变数学定义。

最终提醒
========

高质量实验不是要求 RAVEN-MCS 在每个指标、每个场景都排名第一。
真正的高质量证据必须符合方法机制和理论边界：

- Balanced 场景不明显伤害；
- opportunity/observation/use 三类偏置产生可分解错位；
- Complete 场景改善 target risk；
- 两阶段 correction 优于只校正一个阶段；
- instantaneous calibration 与 debt 作用不同；
- SimOracle 给出统计校正参考；
- weak support 产生 reachability residual；
- hidden confounding 产生无法消除的 residual；
- pair discrepancy 比只看最终 group proportion 更接近目标风险；
- overhead 有明确、可复现的规模曲线。

严禁伪造结果、静默换数据、修改测试口径、使用不同事件轨迹、
删除不利种子或在测试集上继续调参。
